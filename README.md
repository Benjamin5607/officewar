# 오피스 워 오락실 · Office War Arcade

직장 생활을 소재로 한 **6-in-1 레트로 픽셀 아케이드**. 모두 순수 HTML5 + Canvas + Vanilla JS로 만들어졌고, 별도 빌드 없이 정적 호스팅으로 바로 돌아갑니다. DOS 시절 2D 픽셀 그래픽 감성을 목표로 했습니다.

## Play now (GitHub Pages)

**https://benjamin5607.github.io/officewar/**

## 실행 방법

정적 파일 서버로 루트 폴더를 열면 됩니다.

```bash
# Node가 있으면 포함된 초경량 서버 사용
node serve.js 8080
# 그다음 브라우저에서 http://localhost:8080 접속
```

또는 GitHub Pages 등 아무 정적 호스팅에 폴더째 올리면 됩니다. 모바일에서는 홈 화면에 추가하면 PWA(전체화면)로 실행됩니다.

## 언어 설정 (한국어 / English)

- 모든 화면 **우상단의 `KO / EN` 토글**로 언어를 바꿉니다.
- 선택한 언어는 `localStorage`(`owa_lang`)에 저장되어 **허브·6개 게임 전체에서 공유**됩니다. 한 곳에서 바꾸면 다른 게임에도 그대로 적용됩니다.
- UI뿐 아니라 **스토리·대사·엔딩·퀴즈 등 콘텐츠 전체**가 두 언어로 제공됩니다.
- 공통 로직은 `shared/i18n.js`에 있습니다: DOM 요소의 `data-en` 속성을 스왑하고(`applyDom`), JS 동적 텍스트는 `I18N.t(ko, en)`로 뽑습니다. 원작 슈팅(`officewar/`)은 자체 i18n을 쓰되 같은 `owa_lang` 값을 읽어 동기화됩니다.

## 조작

- **모바일**: 각 게임의 화면 버튼(방향 패드 / 공격 / 필살 등)
- **PC**: 방향키·WASD 이동, 게임별 공격/액션 키 (화면 하단 안내 참고)
- 화면을 한 번 탭/클릭하면 레트로 효과음(WebAudio)이 켜집니다.

## 구조

```
index.html            아케이드 허브 (게임 캐비닛 메뉴)
manifest.webmanifest  PWA 매니페스트
shared/
  retro.css           공용 레트로/픽셀 스타일 + CRT 스캔라인
  retro.js            공용 유틸(픽셀 스프라이트, 효과음, 게임 루프)
  i18n.js             공용 언어 설정(KO/EN 토글, 저장, DOM 번역)
  hub.js              허브 화면 로직 + 캐비닛 썸네일
  icon.svg            앱 아이콘
games/
  puzzle/  rpg/  horror/  dating/  fighting/
officewar/            원작 슈팅 게임 (클론된 리포지토리)
serve.js              로컬 테스트용 초경량 정적 서버
```

## 그래픽

- **인게임 캐릭터 스프라이트**는 90년대 KOF / 영웅전설 수준을 목표로 한 **풀바디 픽셀 아트**입니다(외곽선·셀 셰이딩·VGA 256색 감성).
  - 격투: 10인 전신 파이터 스프라이트 `games/fighting/img/fb_*.png` — 잽/강타/가드/피격/필살/KO에 따라 리언·스쿼시·틴트로 애니메이션.
  - RPG: 스테이플러 검 용사·최종보스 김부장·몬스터(서류뭉치/긴급메일/복사기 골렘) `games/rpg/img/rp_*.png`.
  - 호러: 지친 김부장·도플갱어 유령 `games/horror/img/hz_*.png`(측면 스크롤).
- 생성 스프라이트는 배경 없는 투명 PNG가 필요해, `tools/alpha_key.js`(가장자리 플러드필)로 흰 배경을 알파로 제거했습니다. 셔츠 등 **내부 흰색은 외곽선에 둘러싸여 보존**됩니다.
- 격투 10인의 **셀렉트/VS 초상화**(`fighter_*.png`), 육성 게임 **CG 일러스트**(`games/dating/img/`), RPG·호러·격투 **배경**도 VGA 256색 감성으로 생성해 포함했습니다.
- 이미지 로드 전에는 기존 **절차적 픽셀 아트**로 폴백합니다.
